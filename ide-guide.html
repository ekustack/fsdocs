FSCSS IDE guide

Browser IDE for FSCSS — multi-file workspace, live compile, preview, components, and export

Open IDE xfcmds guide Single app · Monaco · localStorage workspace

What it is

The FSCSS IDE is a browser workspace for FSCSS. You can edit several files, compile live, preview HTML, search the component registry, run terminal commands, and export CSS, HTML, ZIP, or a JSON backup.

It loads the compiler from jsDelivr (esm.min.js). You can change the compiler version in settings or with the terminal command version x.y.z.

Layout

  • Top bar: sidebar toggle, command palette, Run, Preview, Auto, Export menu, Import, theme, settings.
  • Left strip: Files, Components, Snippets, Tools — plus Docs and Shortcuts at the bottom.
  • Center-left: file tabs and the editor.
  • Center-right: CSS output and Preview (two tabs).
  • Bottom: Terminal and Problems.
  • Status bar: compiler state, error count, cursor position, language, last save, compiler version.
  • Resizing: drag the dividers for sidebar, editor/output split, and bottom panel. On phones the sidebar overlays the editor and panes stack vertically.

Quick start

  1. Open main.fscss and write some FSCSS.
  2. Press Ctrl+Enter to compile. CSS appears on the right.
  3. Press Ctrl+Shift+Enter to compile and open the live preview.
  4. Use Export to download the result.

On Mac, use Cmd in place of Ctrl.

Files Alt+1

  • Types: .fscss, .xfscss, .css, .html, .js, .json, .md, .txt.
  • New file: Alt+N. No extension → .fscss is added.
  • Folders: type a path like components/card.fscss and the folder appears in the tree.
  • Name cleanup: spaces become dashes.
  • Row actions (hover): set as entry (star), rename, duplicate, delete.
  • Entry file: compiles when the active tab is not an .fscss file. Marked with a star.
  • Tabs: click to switch; X or middle-click to close; Alt+[ / Alt+] to cycle.
  • Examples: under the tree — basic, variables, pattern, imports, debug — load into examples/.
  • Welcome screen: shows when every tab is closed.

Editor

  • Engine: Monaco with FSCSS syntax highlighting.
  • Autocomplete: triggers such as def, use, var, arr, rand, imp, kf, event, pat — snippets with tab stops.
  • Monaco: find, replace, comment toggle, multi-cursor, etc.
  • Problems: compile errors in the Problems tab and as red markers when the message includes a line number. Click a problem to jump.

Compiling and output

  • Run (Ctrl+Enter): active .fscss, or the entry file otherwise.
  • Compile all: every .fscss file — palette and Tools panel.
  • Auto (Alt+A): compile 700 ms after you stop typing.
  • Compile-time logs: exec(_log, …) and similar appear in the Terminal.
  • CSS tab: read-only output with copy and download.
  • Preview tab: builds from index.html (or a default), compiled CSS from all .fscss files, plain .css files, and .js as a module script.
  • Preview extras: width (Full, 768, 375), reload, open in new tab. console.* and preview errors go to the Terminal.

Components Alt+2

  • Source: public libs.json, then each repo’s package.json (main, then master). Falls back to known repos if fetch fails.
  • Cards: name, version, description, keywords.
    • Import — inserts @import((*) from name) at the top of the current FSCSS file (skips if already present).
    • Copy — copies the import line.
    • Repo — opens GitHub.
  • Search: name, description, author, keywords.
  • Cache: 30 minutes; refresh forces reload.
  • Chips: e.g. flex-control, icon-mask, st-core, circle-progress — confirm import names against each package.

Network required for registry and remote @import.

Snippets Alt+3

Built-in snippets include @define, @use, variables, @arr, @random, @import, keyframes, -*- prefixes, %n(), @event, @obj, @fun, pattern(), num(), and exec(_log/_warn).

Click to insert with tab stops. Also available via autocomplete and the command palette.

Tools Alt+4

  • Format: brace-based re-indent (backtick blocks left alone).
  • Beautify / Minify: apply to CSS output.
  • Also: Copy CSS, Share link, Compile all, Set as entry, wrap/minimap toggles, Open preview, Docs, Reset.
  • Stats: after each compile — input/output size, gzip size, rules, lines, compile time.

Terminal and Problems

Ctrl+` focuses the terminal; Ctrl+J shows or hides the bottom panel. Filters: All, Info, Warn, Error. History with Up/Down; Tab completes commands and file names.

Export and import

Export menu

  • Current file
  • Compiled CSS / minified CSS
  • Standalone HTML page
  • ZIP (project files + dist/*.css)
  • JSON backup
  • Copy CSS / copy share link

Import: Import button, drag-and-drop files, or JSON backup (Merge or Replace all).

URL load: #code=… or #run?code=… creates shared.fscss and compiles. #run?code= matches the fscss-to-css page pattern.

Command palette

Ctrl+Shift+P or F1 — search commands, files, examples, and snippets. Arrows + Enter; Esc to close.

Developer settings

Gear icon in the top bar.

  • Display: theme, font size, word wrap, minimap.
  • Compile while typing: same as Auto in the top bar.
  • Entry file: default compile target.
  • Compiler version: type a version and Load — from cdn.jsdelivr.net/npm/fscss@<version>/esm.min.js. Terminal: version 1.2.6.
  • Console: compiler exposed as window.xfscss.
  • Saving: autosave to localStorage (keys fside:). Reset workspace clears those keys.

Good to know

  • @import and component loading need a network connection.
  • Preview runs in a sandboxed iframe — no localStorage or same-origin access to the parent.
  • If the browser blocks localStorage (some embedded viewers), work will not persist — export a JSON backup.
  • Error markers appear only when the compiler message includes a line number.
