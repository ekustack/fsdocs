Variable fallback operator

Starting from FSCSS v1.1.13, you can define a default value directly inside a variable declaration using:

property: $/variable || fallback;

FSCSS resolves the value in this order:

  • If the variable exists → use it
  • Otherwise → use the fallback value

Basic fallback usage

Style store with built‑in defaults

v1.1.13

Define a component (style store) that supplies fallback values. When variables are missing, the fallback is used automatically.

FSCSS
/* Component definition with fallbacks */
str(Button#1, "
  background: $/bg || #06f;
  color: $/color || white;
  border: $/border || 2px solid #06f;
  padding: 0.75rem 1.5rem;
  border-radius: 40px;
  font-weight: 600;
  cursor: pointer;
  transition: 0.2s;
")

/* Usage – without setting any variables */
.btn-default {
  Button#1
}

/* Usage – with custom variables */
.btn-custom {
  $bg: linear-gradient(145deg, #8b5cf6, #3b82f6);
  $color: #fff;
  $border: 2px solid #3b82f6;
  Button#1
}
Compiled CSS
.btn-default {
  background: #06f;
  color: white;
  border: 2px solid #06f;
  padding: 0.75rem 1.5rem;
  border-radius: 40px;
  font-weight: 600;
  cursor: pointer;
  transition: 0.2s;
}

.btn-custom {
  background: linear-gradient(145deg, #8b5cf6, #3b82f6);
  color: #fff;
  border: 2px solid #3b82f6;
  padding: 0.75rem 1.5rem;
  border-radius: 40px;
  font-weight: 600;
  cursor: pointer;
  transition: 0.2s;
}

Left button uses fallback (#06f), right button uses provided gradient.

Required variables (strict mode with $var!)

Enforcing mandatory variables

required

If a variable is marked with ! and not provided, FSCSS will warn. This is useful for critical properties that must be set by the user.

FSCSS
/* Strict card component */
str(CardBase, "
  background: $/surface || #f8fafc;
  padding: 2rem;
  border-radius: 24px;
  /* required variable – must be set by user */
  box-shadow: $/shadow!;
  border: 1px solid $/borderColor || #e2e8f0;
")

/* correct usage: provides $shadow */
.card-valid {
  $shadow: 0 20px 25px -5px rgba(0,0,0,0.1);
  CardBase
}

/* would trigger warning (missing $shadow!) 
   .card-invalid { CardBase } 
*/
Compiled CSS
.card-valid {
  background: #f8fafc;
  padding: 2rem;
  border-radius: 24px;
  box-shadow: 0 20px 25px -5px rgba(0,0,0,0.1);
  border: 1px solid #e2e8f0;
}

Required shadow

$shadow! was provided, so it works.

If $shadow! were missing, FSCSS would show a warning (no fallback).

Plugin‑friendly components

Ship components that always work

design system

Imagine distributing a Avatar component. With fallback operator, users can override only what they need.

FSCSS (plugin code)
/* plugin/avatar.fscss – shipped with defaults */
/* helper event for it to works with %n...*/
@event token(size){
  el{
    return: $/size || 48px;
  }
}

str(Avatar, "
  display: inline-flex;
  align-items: center;
  justify-content: center;
  %2(width, height[:@event.token(0);])
  background: $/bg || #cbd5e1;
  border-radius: $/rounded || 9999px;
  color: $/color || #1e293b;
  font-weight: 600;
  border: $/border || 2px solid white;
  box-shadow: $/shadow || 0 4px 6px -1px rgb(0 0 0 / 0.1);
")

/* user project – minimal setup */
.user-avatar {
  $size: 56px;
  $bg: #3b82f6;
  $color: white;
  Avatar   /* rest fallback: rounded full, white border, default shadow */
}

/* another user – different style */
.outline-avatar {
  $size: 40px;
  $bg: transparent;
  $border: 2px solid #8b5cf6;
  $color: #8b5cf6;
  $rounded: 12px;  /* square with rounded corners */
  Avatar
}
Compiled CSS
.user-avatar {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 56px;
  height: 56px;
  background: #3b82f6;
  border-radius: 9999px;
  color: white;
  font-weight: 600;
  border: 2px solid white;
  box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.1);
}

.outline-avatar {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 40px;
  height: 40px;
  background: transparent;
  border-radius: 12px;
  color: #8b5cf6;
  font-weight: 600;
  border: 2px solid #8b5cf6;
  box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.1);
}

📘 Syntax reference

Form Description Example
$/var || value fallback if $var is not defined background: $/bg || #06f;
$var! required variable (warning if missing) box-shadow: $shadow!;
$/var || fallback + ! not applicable (fallback is only for optional) —

The fallback can be any CSS value, including gradients, numbers with units, or even @random() functions.
