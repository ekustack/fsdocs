Figured Shorthand CSS

Write less CSS.
Ship the same browser.

FSCSS is a lightweight CSS preprocessor that compiles in the browser or via a Node/CLI build step. No virtual DOM, no runtime framework — it outputs plain CSS, so anything you already know about styling still applies.

.fscss live compile
example 1 / 3
you write
browser gets .css
waiting for compile…

No build required

Drop a CDN script tag and link a .fscss file directly in HTML — it compiles at runtime.

Or compile ahead of time

Install via npm, run the CLI, ship plain .css — nothing FSCSS-specific reaches production.

Setup

Install

Two ways to use FSCSS — pick based on whether you want a build step.

CDN (runtime compile)

.html index.html
<link type="text/fscss" href="style.fscss">
<script src="https://cdn.jsdelivr.net/npm/fscss@latest/exec.min.js" defer></script>

npm (build step)

bash terminal
# package install
npm install fscss@latest

# global CLI
npm install -g fscss
fscss input.fscss output.css
Tutorial

Quick start

  1. Create style.fscss and define a variable with $name: value;, then use it in a normal-looking CSS rule.
  2. Link the file in your HTML with <link type="text/fscss"> and include the CDN exec.min.js script (or run the CLI to output real .css).
  3. Open the page — FSCSS compiles your shorthand into standard CSS the browser understands natively.
.fscss style.fscss
$primary-color: #2563eb;
$border-radius: 8px;

.btn {
  background: $primary-color;
  border-radius: $border-radius;
  padding: 12px 24px;
}
Core Syntax

Core Concepts

$variables

Reusable values, declared once and referenced with $name. Straightforward substitution — no scoping surprises.

.fscss _variables.fscss
$spacing-md: 1rem;

.card { padding: $spacing-md; }

@define — reusable, parameterized blocks

The closest thing FSCSS has to a mixin. Parameters take default values and must be read with @use() — direct references silently fail to resolve.

.fscss _mixins.fscss
@define card(bg: black, color: white, pad: 20px){
  background: @use(bg);
  color: @use(color);
  padding: @use(pad);
}

.box { @card(#007999) }
Two modes: property defines (like the example above, for utility groups) and block defines wrapped in backticks (for full structures like @media queries).

Arrays — @arr

Ordered value collections with index or auto-loop access, plus transform methods in "method mode" (@arr.name!).

.fscss palette.fscss
@arr colors[#3b82f6, #8b5cf6, #06b6d4]

.btn { background: @arr.colors[1]; }          /* indexed */
.alt { background: @arr.colors!.reverse; }    /* method mode */

Common methods: .length .first .last .reverse .shuffle .sort .unit(px) .prefix(btn-) .sum .randint.

Shared properties — %2 to %6, %i

Apply one value to several properties in a single declaration. Built for genuinely related properties — width/height, or a consistent margin/padding/gap set.

.fscss shared.fscss
.square {
  %2(width, height[: 150px;])
}
/* → width: 150px; height: 150px; */

@random

Selects a value from a list (or an @arr) at compile time — useful for generative UI, staggered animation delays, or one-off visual variation. Best paired with a curated array rather than an unrelated grab-bag of values.

.fscss random.fscss
@arr accents[#3b82f6, #8b5cf6, #06b6d4]

.card { border-color: @random(@arr.accents); }

@import — modular files

Split variables, defines, and components into focused files, then pull them together with @import(exec(...)).

.fscss main.fscss
@import(exec(_variables.fscss))
@import(exec(_mixins.fscss))
@import(exec(_buttons.fscss))
Avoid circular imports — file A importing file B which imports file A will loop and break the build.
Ecosystem

Plugin library

Community and first-party plugins under the fscss-ttr org extend FSCSS with ready-made, zero-JS component systems.

charts

st-core.fscss

Line and area charts, dashboard stat cards, and progress bars — driven entirely by clip-path and CSS custom properties. Used in dashboard templates on DevTemple.

progress

circle-progress.fscss

Animated circular progress rings using conic-gradient, no canvas or SVG required.

layout

flex-control.fscss

Shorthand flexbox utilities for common layout patterns without hand-writing each flex property.

icons

icon-mask.fscss

CSS mask-based icon utilities — style icons with plain background / color instead of swapping SVG files.

All plugins install the same way: import the whole file with import((*) from plugin-name), then call the @defines it exposes. A plugin file that only defines mixins produces no CSS until something imports and calls it.
